# Введение

Light — это декларативный реактивный GUI-фреймворк для Rust, который сочетает привычную HTML-разметку, реактивную модель данных и собственный оконный рендерер на `winit` + `softbuffer`.

## Философия

Light строится на пяти принципах:

1. **Декларативность.** Вы описываете *что* должно быть на экране, а не *как* это перерисовать. UI — это функция от состояния.
2. **Компиляция вместо интерпретации.** Шаблоны превращаются в Rust на этапе сборки. В рантайме нет HTML-парсера, ошибки разметки видны компилятору с указанием файла и строки.
3. **Гранулярная реактивность.** Изменение свойства перерисовывает только зависящие узлы дерева. `#[proxy]` превращает поля структуры в реактивные ячейки.
4. **Нативные окна без обвязки.** Безрамочные окна, кастомный titlebar, модальные окна, мультиокна — из коробки.
5. **Платите только за используемое.** Каждая подсистема — Cargo-фича; код выключенных фич не попадает в бинарник.

По духу Light ближе всего к связке Vue + Electron: вы пишете HTML-разметку с директивами (`v-if`, `v-for`, `v-model`), описываете логику на Rust, а рендерингом занимается нативная оконная система. Никакого JavaScript, никакого веб-стека, никакого Electron.
